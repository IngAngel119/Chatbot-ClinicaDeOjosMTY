# Chatbot-ClinicaDeOjosMTY
## Descripción

Prototipo de asistente conversacional desarrollado con Python y NLTK para orientar a los usuarios sobre citas, servicios, horarios, ubicación y requisitos generales de una clínica oftalmológica.

## Objetivo

Explorar cómo un chatbot basado en reglas puede automatizar respuestas administrativas frecuentes y apoyar al personal de una clínica.

## Tecnologías

Python 3.10 o superior
NLTK
Google Colab
GitHub

## Ejecución

Abrir el notebook en Google Colab.
Ejecutar las celdas en orden.
Iniciar la conversación mediante la función iniciar_chat().
Ejecutar los casos de prueba y revisar el resumen.
Descargar el archivo CSV con los resultados.
Alcance y limitaciones

El chatbot utiliza reglas y patrones de texto. No se conecta a una agenda real, no confirma disponibilidad y no modifica citas existentes. La información institucional incluida es ficticia y debe sustituirse por información autorizada antes de cualquier uso operativo.

El asistente no proporciona diagnósticos ni sustituye la atención médica.

## Pruebas

El notebook incluye pruebas funcionales para las intenciones conversacionales definidas y genera un archivo CSV con los resultados obtenidos.
